This page needs to be served

The app uses ES modules, which browsers only load over http(s) — not from a double-clicked file.

Run it: python3 -m http.server 5500 --directory front-end, then open http://127.0.0.1:5500/

The back-end is not running

This app keeps your subjects and reviews on a small Flask server. Start it in a second terminal, then reload this page.

Start it: cd back-end && python app.py

It should say: Running on http://127.0.0.1:5050

On GitHub Codespaces, start it with python3 -m flask run --host=0.0.0.0 --port=5050, then open the Ports tab and set port 5050 visibility to Public.
